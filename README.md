# Ayd Sports Academy

Welcome to **Ayd Sports Academy** - Your Premier Sports Training Platform

## Overview

Ayd Sports Academy is a comprehensive sports management and training application designed to help athletes, coaches, and sports enthusiasts achieve their fitness and athletic goals. Our platform provides tools for training management, performance tracking, and community engagement.

## Features

- 🏃 **Training Programs** - Customized workout plans for various sports
- 📊 **Performance Tracking** - Monitor progress and achievements
- 👥 **Coach Management** - Connect with experienced coaches
- 📅 **Schedule Management** - Organize classes and training sessions
- 💪 **Fitness Analytics** - Detailed performance metrics and insights
- 🎯 **Goal Setting** - Set and track personal fitness goals
- 🏆 **Leaderboards** - Compete with other athletes

## Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/veervig12-ui/Ayd-app.git
   cd Ayd-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the application**
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`

## Usage

### For Athletes
- Create an account and complete your profile
- Browse available training programs
- Enroll in courses and track your progress
- View performance analytics and achievements

### For Coaches
- Set up your coaching profile
- Create and manage training programs
- Monitor student progress
- Provide feedback and guidance
